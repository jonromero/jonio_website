## About the Book 

This is not a normal book. By far.

It might be a book about how to build Startups, make money and never having to work again. But it is mostly a book about **you**. Crazy right? A book about specifically you.  

![](images/bookwrite.jpg)

Seriously. It is the first book that talk about that in a way never talked about before. I am not sure if it is good or bad but it is different.

Also the book is written WITHOUT the use of A.I. To be more exact:

> No A.I has been used to write any of this. If you want an A.I version, ask your favorite LLM to write a book based on my posts at jon.io.

There are literally parts where A.I could not have written. I guarantee you that. Again, not sure if this is good or bad.
